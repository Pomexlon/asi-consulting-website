AiFILE

Find the thing you mean.

AiFILE helps you search the folders you choose, look inside supported documents, rank likely matches and keep project notes close—without reorganising your original files.

Recorded beta demonstration

Your Mac, remembered.

The demo shows the AiFILE beta workflow: choose folders, search what you remember, use supported file text and likely matches, then keep useful project context on the memory board.

This is a recorded beta demonstration. The final public release may differ in packaging, supported macOS versions and interface details.

What it can do now.

  • Search filenames, locations, labels and some spelling variations.
  • Search text extracted from supported files where extraction succeeds.
  • Search saved EML email text; there is no live inbox connection.
  • Search project cards and quick notes, and include Apple Notes only when explicitly imported.
  • Rank likely matches first and open the original file from its existing location.
  • Connect multiple chosen folders, rescan them, and back up AiFILE project notes and labels.

What it deliberately does not claim.

  • It does not search every protected or hidden location on a Mac.
  • It does not promise full text extraction from every file type or every page.
  • It does not provide general image or scene understanding.
  • It does not continuously watch folders in the current beta.
  • It does not move, rename or reorganise your source files as part of search.

Local-first by design.

The current beta keeps its catalogue and project notes under the user’s Mac Application Support area. Users choose the folders to catalogue. Original files remain in place.

Cloud placeholders or unreadable files may be searchable only by name and location. See the AiFILE privacy note for the current release model.

Release status.

Free Mac beta — final public package in preparation.

The public download is intentionally not enabled yet. The final release package is being completed and will publish its exact version, supported macOS versions, signing/notarisation state, installation steps, known limitations and release notes when frozen.
