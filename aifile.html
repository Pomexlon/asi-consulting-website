AiFILE

Find the thing you mean.

AiFILE helps you search the folders you choose, look inside supported documents, rank likely matches and keep project notes close—without reorganising your original files.

Recorded beta demonstration

Your Mac, remembered.

The demo shows the AiFILE beta workflow: choose folders, search what you remember, use supported file text and likely matches, then keep useful project context on the memory board.

This is a recorded beta demonstration. The final public release may differ in packaging, supported macOS versions and interface details.

What it can do now.

  • Search filenames, locations, labels and some spelling variations.
  • Search text extracted from supported files where extraction succeeds.
  • Search saved EML email text; there is no live inbox connection.
  • Search project cards and quick memories saved in AiFILE. Apple Notes is not connected.
  • Rank likely matches first and open the original file from its existing location.
  • Connect multiple chosen folders, check for changes while AiFILE is running, and back up saved board items.

What it deliberately does not claim.

  • It does not search every protected or hidden location on a Mac.
  • It does not promise full text extraction from every file type or every page.
  • It does not provide general image or scene understanding.
  • Automatic checks run only while AiFILE is open and enabled. Search uses the catalogue already built, which becomes more complete as scanning progresses.
  • It does not move, rename or reorganise your source files as part of search.

Local-first by design.

The current Free preview keeps its catalogue, extracted text and saved memories in its macOS app container. Users choose the folders to catalogue. Original files remain in place. This local storage has no separate AiFILE password or application-level encryption.

Cloud placeholders or unreadable files may be searchable only by name and location. See the AiFILE privacy note for the current release model.

AiFILE Pro · in development

Find it. Then put it in order.

Free remains focused on finding files and keeping useful memories close. Pro is being developed for people who want to review changes to their files before making them.

  • Reviewed renaming: check a proposed name before changing a file.
  • Organising by category: review where a selected file should go before moving it.
  • Comparing copies: review file details when deciding which copy you need.
  • Change history and undo: review recorded changes and undo supported operations.

These are planned Pro benefits. Work on individual files remains subject to your review and folder permissions. Pro is not available to buy yet; there is no paid upgrade or checkout on this page.

Updated 7 October 2026. Final features and availability will be described with the released product.
